# moonmodel

One field description; JSON Schema, OpenAPI, SQL and SDL are its projections.

> **Status: planned.** The repository is set up; nothing is
> implemented yet.

MoonBit already turns a struct into JSON and back — `derive(ToJson)`,
`derive(FromJson)`, `@json`'s `JsonPath`. That is not what this is for.

The same concept is currently written four times over: moonapi's schema fields,
moonorm's model columns, moongql's SDL fields, moonschema's documents. One
description, projected:

| Projection | Consumer |
|:--|:--|
| JSON Schema / OpenAPI | moonapi, moonschema |
| SQL columns and DDL | moonorm |
| GraphQL SDL | moongql |

MoonBit has no reflection and `derive` takes no field attributes, so a
description is written — by hand, or generated by `mctl`.

## Install

```bash
moon add moonbitstack/moonmodel
```
